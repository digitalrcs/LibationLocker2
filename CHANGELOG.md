# Changelog

## 2.1.0 - 2026-11-01

- Replaced Usage & History charts with locally bundled Apache ECharts 6.1.0: consumption line/area, usage and reorder bars, and stepped stock history.
- Preserved chart toggles and expanded views, with theme-aware tooltips, date zoom sliders, responsive resizing, and accessible descriptions.
- Included zero-usage weeks and corrected empty-state handling in expanded charts.

## 2.0.0 - 2026-11-01

- Prepared a credential-free GitHub distribution package.
- Added LocalDB, Express, and full SQL Server setup automation.
- Added optional fictional demo inventory, recipes, and history.
- Replaced the hard-coded fallback login with an environment-configured bootstrap administrator.
- Added README, documentation, wiki sources, security guidance, and packaging scripts.
- Added inventory history, usage analytics, reorder estimates, and recent-change views.
- Added resilient LM Studio timeouts, streaming support, provider-controlled token limits, and AI availability status.
