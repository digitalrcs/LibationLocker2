# Libation Locker 2 Server Edition v2.0.0

The first public versioned release of the self-hosted ASP.NET Core and SQL Server edition of Libation Locker.

## Highlights

- Bar inventory with quantities, remaining amounts, ratings, tags, and shopping needs.
- Recipe library, import/export, inventory history, and usage analytics.
- Optional LM Studio integration with streaming and availability status.
- Database-backed users and roles with an explicitly configured bootstrap administrator.
- Branded documentation, fictional demo data, and SQL Server setup scripts.

## Downloads

- **LibationLocker2-2.0.0-app.zip**: framework-dependent application with database scripts and documentation. Requires the .NET 8 ASP.NET Core Runtime and SQL Server. For IIS, install the .NET 8 Hosting Bundle.
- **LibationLocker2-2.0.0-source.zip**: complete source snapshot for this release. Requires the .NET 8 SDK to build the project.
- **SHA256SUMS.txt**: SHA-256 checksums for both packages.

## First installation

1. Extract the application ZIP into a new directory.
2. Follow `docs/database.md` to create a SQL Server database. Optional demo data is fictional.
3. Configure the connection string and temporary bootstrap administrator using environment variables as described in `docs/configuration.md`.
4. From the extracted directory, run `dotnet ./app/LibationLocker.Web.dll --contentRoot ./app --urls http://localhost:5058`, or follow `docs/deployment-iis.md` to host the `app` directory with IIS.
5. Create a permanent administrator, disable bootstrap access, and remove its credentials.

For an existing installation, back up the database and deployment files first. Preserve your environment settings, IIS configuration, and Data Protection keys. Review the database scripts and deployment guide before replacing application files.

## Validation and limitations

The release application is built in Release configuration. Source-package auditing and JavaScript syntax checks are included in repository CI. These checks do not constitute full database, browser, or production regression testing.

SQL Server is required; SQLite is not supported. AI features require a separately configured compatible endpoint. No runtime, SQL Server installation, production credentials, or personal inventory data is bundled.
