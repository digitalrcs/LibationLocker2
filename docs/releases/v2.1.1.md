# Libation Locker 2 Server Edition v2.1.1

Compatibility update: inventory and recipe charts now start in 2D. Browsers without WebGL keep working charts and show a disabled "3D unavailable" control instead of attempting a 3D view. Usage & History remains SVG-based ECharts.

## Downloads and upgrade

- **LibationLocker2-2.1.1-iis-upgrade-win-x64.zip**: use for existing Windows x64 IIS installations. Application files are at the ZIP root; all `web.config` and `appsettings*.json` files are excluded.
- **LibationLocker2-2.1.1-app-win-x64.zip**: full Windows x64 framework-dependent application under `app/`, with generic configuration and setup documentation for a new installation.
- **LibationLocker2-2.1.1-source.zip**: tagged source.
- **SHA256SUMS.txt**: checksums for all ZIPs.

Requires .NET 8; IIS requires the .NET 8 Hosting Bundle and a 64-bit application pool. There are no database or server-configuration changes from v2.1.0.

Back up the site, stop its application pool, and copy the upgrade ZIP contents over the site without deleting or mirroring the destination. Keep your configuration, Data Protection keys, images, exports, and logs. Restart the pool and refresh the browser. The [v2.1.0 deployment and legacy-login guidance](https://github.com/digitalrcs/LibationLocker2/blob/main/docs/releases/v2.1.0.md) still applies.

The compatibility check deliberately disabled WebGL and verified inventory charts, recipe charts, expanded views, disabled 3D controls, and ECharts without JavaScript errors. A refresh may resolve a transient WebGL problem on its own; this patch adds a fallback for browsers where WebGL is unavailable. Production IIS and database behavior must still be checked after upload.
