# Libation Locker 2 Server Edition Wiki

Welcome to the DigitalRCS Libation Locker 2 Server Edition wiki. This .NET 8 application provides centralized SQL Server inventory, recipes, user accounts, item history, usage analytics, import/export, and optional LM Studio integration.

This is not the ESP32 firmware project. Start with [Server Edition vs ESP32 Edition](Server-Edition-vs-ESP32-Edition) if you are deciding which version to install.
