# LM Studio

AI is optional and disabled by default. Start LM Studio, load a model, enable its local server, then configure the endpoint under **Admin > AI Provider**. Use `http://127.0.0.1:1234` when LM Studio runs on the same host.

Set max tokens to `0` to let LM Studio and the model decide. Increase the application timeout for slower models. Inventory data is sent to the configured endpoint when inventory context is enabled.
